# Item plans

One file per medium or large item (a development step, a larger fix), written before any code: `phase-N-step-M.md` or `short-name.md`, at most about 150 lines.

Contents: verified facts with the file where each was found; decisions and why; pitfalls; done criteria; the tasks for the agents and the commit split. At the end, a report of at most one page: what was built, where the plan was wrong, questions for the next work.

See CLAUDE.md, How we work.
